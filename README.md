# Brazil Go-To-Market Notes

This repository contains high-level notes, frameworks, and observations
from 10+ years building and scaling B2B SaaS and fintech sales in Brazil
and LATAM.

Topics include:
- Market entry considerations for Brazil
- Enterprise sales in regulated environments
- Working with compliance, risk, and legal teams
- Building early sales structures in high-growth startups

This repository is intended as a knowledge-sharing space rather than
production code.
